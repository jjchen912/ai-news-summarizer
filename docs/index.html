03 / How to run

怎麼執行？

本機執行（Windows PowerShell）

  1. 安裝 uv，使用官方安裝指令。
  2. 取得 Gemini API Key，建立本機 .env（不加入 Git）。
  3. 安裝並執行以下命令，輸出至 docs/result.json。
uv sync
uv run python src/main.py --mode ai
uv run python -m http.server 8000 --directory docs

在瀏覽器開啟 http://localhost:8000

GitHub Actions 自動部署

  1. 推送到 main 分支或手動執行 workflow_dispatch。
  2. 安裝 uv、執行測試，並使用 Secret 呼叫 Gemini API。
  3. 上傳網站檔案到 Pages Artifact，部署至 github-pages 環境。

設定 Repository → Settings → Pages → Source → GitHub Actions。金鑰放在 Repository secrets，不會公開到網站。

04 / AI disclosure

AI 使用說明

使用了哪些工具？

Gemini API：在執行階段對新聞進行繁體中文摘要及 JSON 結構化輸出。

ChatGPT：協助規劃初版 Python 程式、網站版型、測試與 README；程式與部署流程需由提交者自行實測及審查。

自己做了哪些事？

專案目前包含欄位格式檢查、三項重點數量驗證、API 金鑰保護、單元測試、示範模式與 Pages 自動部署。提交前應由作者親自運行測試、確認 GitHub Actions 綠燈，並在 README 的「個人驗證紀錄」如實填入實際操作、修改與觀察。
